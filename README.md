# TabbedExplorer

Win10 上带标签的资源管理器：每个虚拟桌面一个窗口，同桌面按 Win+E 合并成新标签，退出后按桌面记住标签。
文件列表 / 右键菜单 / 拖放 / 缩略图由 Windows shell 原样提供。

标签条最右边的齿轮是设置（齿轮和托盘右键是同一份），数据和配置全在**程序目录下的 `data\`**，
拷走整个文件夹就能带走（绿色便携）。

## 编译与运行

1. `build.bat` —— 用系统自带的 .NET Framework 编译器，不装任何东西。
2. `run.bat` —— 启动（常驻托盘，不自动弹窗口）。
3. 按 **Win+E** 试：当前桌面开一个窗口；再按一次，合并成第二个标签。
4. 换一个虚拟桌面按 Win+E：那边是独立的一组标签。

## 开机自启（要接管 Win+E 就需要常驻）

- `install_autostart.bat` 写入当前用户的启动项
- `uninstall_autostart.bat` 移除

## 快捷键

| 键 | 作用 |
|---|---|
| Win+E | 在当前桌面的窗口里新开一个「此电脑」标签（没有窗口就建窗口） |
| Ctrl+T | 新标签 |
| Ctrl+W | 关标签 |
| Ctrl+Tab / Ctrl+Shift+Tab | 切换标签 |
| Ctrl+1..9 | 跳到第 N 个标签 |
| Ctrl+L | 地址栏 |
| Alt+← / → | 后退 / 前进 |
| Alt+↑ | 上一级 |
| F5 | 刷新 |

拖文件夹到标签栏或内容区 = 新标签打开。双击标签条空白处 = 新标签。
鼠标**停在标签上**会显示完整文件夹名（标题被省略号截了也能看全）。
标签条上「+」紧跟在最后一个标签右边（浏览器那样），最右边那枚齿轮是设置。

## 标签记忆

每张虚拟桌面各自记一套标签，存在**程序目录下的 `data\desktops.txt`**
（纯文本，一行一个标签，`*` 是当时选中的那个）。标签有变动就写盘，退出前再存一次；
下次在哪张桌面按 Win+E，就还原哪一套。不想留着就把设置里的「保留标签页」关掉。

记的是**你最后停在哪儿**（读地址栏那个字符串），不是当初打开时给的路径。
库之类没真实路径的项（地址栏给的是「视频」这种显示名）会被跳过，其余照常还原。

## 设置

最右边那枚齿轮弹出的菜单（**托盘右键里的「设置」是同一份内容**）。全部存在
**程序目录下的 `data\settings.txt`**，纯文本，手改也行：

| 项 | 值 | 说明 |
|---|---|---|
| `capture` | `perdesktop`（默认） / `migrate` | 捕获方式：每张虚拟桌面各一个窗口，还是全进程一个窗口 + Win+E 搬过来（1.0.0 的老做法） |
| `keeptabs` | `1`（默认） / `0` | 是否保留标签页；关掉就是每次打开都只有一个「此电脑」 |
| `theme` | `system`（默认） / `light` / `dark` | 颜色模式 |
| `tabwidth` | `112`（默认，64~240） | 标签页宽度（逻辑像素） |
| `tabautofit` | `1`（默认） / `0` | 标签挤不下时是否自动缩窄；关掉就是固定宽度 |

改完整项就立刻生效（切捕获方式还会把记忆搬个家，只在目标那一边还空着时才搬）。

⚠ **颜色模式的限制**：嵌进来的 explorer 是**独立进程**，它按**系统**主题画自己那一片，
我们改不了别人进程的开关。所以强制浅/深只改得动我们自己画的外壳
（标题栏 / 标签条 / 菜单 / 四周边框），文件列表仍跟系统。

## 数据与便携

`settings.txt`（设置）、`desktops.txt`（标签记忆）、`log.txt`（日志）都在**程序目录的 `data\`** 下 ——
整个文件夹拷到别的机器/U 盘就能直接用，不往系统里写东西。
程序目录写不动时（比如放进 `Program Files`）自动退回 `%APPDATA%\TabbedExplorer`。
从旧版本升上来的第一次启动，会把老位置的数据抄一份过来（只补缺，不覆盖）。

## 卸载 QTTabBar

两套并存会抢 Win+E，必须二选一。`uninstall_qttabbar.bat` 会卸掉机器上已装的 QTTabBar（卸完需要重启资源管理器）。
