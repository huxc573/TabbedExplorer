# TabbedExplorer —— 给Win10资源管理器加标签页（浏览器式）

> **v1.12**（`VERSION` = `1.12.0`）· 作者 [huxc573](https://github.com/huxc573) ·
> 开源地址 [github.com/huxc573/TabbedExplorer](https://github.com/huxc573/TabbedExplorer) · **MIT 协议** ·
> 变更见 [CHANGELOG.md](CHANGELOG.md)

**一句话**：像浏览器一样用Win10资源管理器 —— 标签页、历史记录、恢复关闭的标签、书签栏、可配置设置，
而且标签里那套文件列表 / 右键菜单 / 拖放 / 缩略图**都是Windows原版的**，不是仿制界面。

关键词（方便搜到）：Windows10文件资源管理器多标签页 / 多标签文件管理器 / 资源管理器标签化 /
浏览器式资源管理器 / 接管Win+E / 每个虚拟桌面一套标签 / 绿色便携免安装 / 单文件exe。

## 它解决什么

Win10自带的资源管理器没有标签页，开三个文件夹就是三个窗口，任务栏挤成一排。
Windows11的「标签页」功能在Win10上开不出来（ViVeTool的feature门槛是21536，Win10只到19045）。

TabbedExplorer的做法**不是**重新画一个文件列表，而是：
**把一个真正的资源管理器窗口「搬」进我们窗口里当一个标签**（跨进程 `SetParent`，原窗口降级为子窗口）。
所以文件列表、右键菜单、拖放、缩略图、地址栏、功能区全都是Windows自己那套，
我们只在**上面**套了一条自绘的标签条、**中间**（可关）夹一条书签栏。

```
┌──────────────────────────────────────────────────────┐
│ 标签1  标签2  标签3  +   [历史][恢复][书签] | [齿轮] —□×│  ← 标签条就在最上面
├──────────────────────────────────────────────────────┤
│ 书签栏（Ctrl+Shift+B，夹在标签条和内容之间）         │
├──────────────────────────────────────────────────────┤
│        真·资源管理器窗口（跨进程嵌进来的）             │
│  功能区(文件/主页/共享/查看) → 地址栏 → 文件列表       │
└──────────────────────────────────────────────────────┘
```

标签条那条**空白处兼任标题栏**：按住可以拖窗口（贴边吸附也管用），双击空白是新标签。
最右边依次是历史 / 恢复关闭 / 书签栏 / 设置（齿轮），齿轮单独用一条竖线隔开；
再往右就是窗口自己的**最小化 / 最大化 / 关闭**。

## 主要特性

- **浏览器式标签条**：`+` 紧跟最后一个标签右边；标签上显示**文件夹名**，
  **鼠标停上去**才显示「文件夹名 + 完整路径」（两者一样时只显示一个，不重复）；
  可鼠标拖拽排序；中键 / 标签上的×关闭；
  右键有「复制文件夹名 / 复制完整路径 / 复制标签页 / 在新标签页打开 / 重新打开刚关闭的 /
  **关闭其它标签页 / 关闭左边标签页 / 关闭右边标签页** / 关闭 / 更多选项」。
  标签多到放不下时，标签区底部会出现一条**位置指示条**（滚到哪一段、还剩多少一眼可见）。
- **接管Win+E**，并且**捕获所有新打开的文件夹窗口** —— 从开始菜单、桌面双击打开的文件夹也会收进标签里
  （不想这样可以在设置里关掉，只保留Win+E）。
- **按虚拟桌面分开**：每张虚拟桌面一个窗口、各记一套标签。在「工作」桌面按Win+E，看到的是「工作」那套，
  不会把你从当前桌面拽走。
- **按桌面记忆标签**：关掉程序也记住每张桌面开着哪些标签，下次打开原样还原
  （记的是**你最后停在哪儿**，读地址栏，不是当初传进去的路径）。
- **历史记录（Ctrl+H）**：列出去过的文件夹，挑一个直接开成标签。
- **恢复关闭的标签页（Ctrl+Shift+T）**：点一下恢复最近关的那个，再点一下恢复上上个，依次往回。
- **书签栏（Ctrl+Shift+B）**：**程序自己记**（`data\favorites.json`），不跟着系统收藏夹变
  （第一次跑会从系统的「链接」目录 `%USERPROFILE%\Links` 播种一次，之后只认自己的）。
  栏最左边那枚书签图标点开**书签管理器**（带搜索、重命名、无限嵌套、拖拽整理）；
  **文件夹 / 文件可以直接拖进栏里**；
  栏上右键能「在新标签页打开 / 用默认程序打开 / 复制完整路径 / 从书签移除 / 刷新书签栏 / 隐藏书签栏」。
  书签里自己的文件夹有**专属图标**（蓝文件夹 + 金徽），不会跟磁盘上的真文件夹搞混。
- **两个管理器**：**书签管理器**（树 + 搜索 + 多选 + 拖拽整理）和**历史记录管理器**
  （按天分组、多选、右键一个日期就能整组删）。书签栏左端那枚图标开前者，Ctrl+H 开后者，
  **托盘图标右键里两个都能直达**。
- **新建标签页几乎瞬时**：后台预先备着一个已经加载好的「此电脑」窗口，按下 + / Ctrl+T 时直接用它。
- **独立的设置窗口**：点齿轮（或标签条空白处右键→设置）开一个窗口，
  里面写程序名 / 版本 / 作者 / 开源地址（可点开）/ 简介 + 所有设置项；托盘图标右键那份菜单保持原样。
- **开机自启**（设置项）：开机后只常驻托盘、接住Win+E，不弹窗口。
- **深色/浅色跟随**，窗口**激活/未激活**两套配色（跟原生资源管理器一个逻辑），DPI自适应；
  提示气泡是自己画的（跟着我们的配色走，不是系统那套）。
- **绿色便携**：设置、标签记忆、历史、书签、日志全在**程序目录下的 `data\`**，
  拷走整个文件夹就能带走；程序目录写不动时自动退回 `%APPDATA%\TabbedExplorer`。

## 编译与运行

1. `build.bat` —— 用系统自带的.NET Framework编译器（`csc.exe` + GAC引用），不装任何东西、零NuGet。
2. `run.bat` —— 启动（常驻托盘，不自动弹窗口）。
3. 按 **Win+E** 试：当前桌面开一个窗口；再按一次，合并成第二个标签。
4. 换一个虚拟桌面按Win+E：那边是独立的一组标签。

## 开机自启（要接管Win+E就需要常驻）

设置窗口里的「开机自启」勾一下就行（写的是当前用户的启动项，不需要管理员权限，
启动方式带 `--tray`：只驻留托盘、不弹窗口）。
命令行等价的还有 `install_autostart.bat` / `uninstall_autostart.bat`。

## 快捷键

下面这些（除 Win+E 和 Ctrl+1..9）**都能改**：设置窗口 →「快捷键」页 →
点一下那个方框、直接按你要的组合键（至少要按住 Ctrl 或 Alt）。改完立刻生效，存在 `settings.json`
的 `hotkey_*` 里；跟别的命令撞了会当场告诉你、不改。

| 键（默认） | 作用 | 能改 |
|---|---|---|
| Win+E | 在当前桌面的窗口里新开一个「此电脑」标签（没有窗口就建窗口） | 否（这是接管的目标） |
| Ctrl+T | 新标签（打开「此电脑」） | 是 |
| Ctrl+W | 关标签（最后一个标签关掉=收进托盘，不退程序） | 是 |
| Ctrl+Tab / Ctrl+Shift+Tab | 切换标签 | 是 |
| Ctrl+H | 历史记录 | 是 |
| Ctrl+Shift+T | 恢复刚关掉的标签页 | 是 |
| Ctrl+Shift+B | 显示 / 隐藏书签栏 | 是 |
| Ctrl+1..9 | 跳到第N个标签 | 否（一绑就是一串键） |
| Ctrl+L | 地址栏 | 否（explorer 自己的） |
| Alt+← / → | 后退 / 前进 | 否（explorer 自己的） |
| Alt+↑ | 上一级 | 否（explorer 自己的） |
| F5 | 刷新 | 否（explorer 自己的） |

这些自有快捷键**只在我们自己的窗口是前台时生效**（焦点在嵌进来的 explorer 里也算）——
在别的程序里按 Ctrl+W 照旧是别的程序的事，不会被我们抢走。

拖文件夹到标签栏或内容区 = 新标签打开。双击标签条空白处 = 新标签（单击空白拖动 = 移动窗口）。
标签条空白处右键 = 新建标签 / 历史记录 / 恢复关闭的标签页 / 书签栏 / 关闭其它·左边·右边 / 更多选项。
标签上右键 = 复制名字 / 复制路径 / 新标签打开 / 重开刚关的 / 复制标签页 / 添加到书签栏 / 关闭族 / 更多选项。
鼠标**停在我们自己画的每一个图标上**都会显示它是干什么的（含当前绑定的快捷键）。

### 滚轮怎么用

| 鼠标在哪 | 滚轮做什么 |
|---|---|
| 标签上 | 切上一个 / 下一个标签 |
| 标签右边那排按钮上（历史 / 恢复 / 书签栏 / 齿轮 / 最小化那三个） | **横向滑动标签条**（标签放不下时才有效） |
| 内容区（文件列表里） | 标签放不下时：横向滚标签条；放得下时：原样交给 explorer 滚动列表 |

关于 **Shift+滚轮**：资源管理器的文件列表**本来就有** Shift+滚轮 = 横向滚动（shell 自己实现的，
不经我们）。所以我们只在「标签确实放不下」时才接管内容区的滚轮；放得下时一律放行，
这时你在文件列表里按 Shift+滚轮拿到的就是**原生的横向滚动**（在详细列表视图里能左右移列）。

## 标签记忆

每张虚拟桌面各自记一套标签，存在**程序目录下的 `data\desktops.json`**
（JSON：`desktops` 数组，每张桌面一段，`tabs` 是标签，`active` 是当时选中的那个；
读得懂老的 `desktops.txt`，第一次跑自动迁移并把老文件改名成 `.migrated`）。
标签有变动就写盘（改动攒一小会儿），退出前再存一次；
下次在哪张桌面按Win+E，就还原哪一套。不想留着就把设置里的「保留标签页」关掉。
设置里那个「立即记住当前标签」是**手动存一次** —— 平时本来就自动记，它只管「怕没来得及存」的时候。

记的是**你最后停在哪儿**（读地址栏那个字符串），不是当初打开时给的路径。
库之类没真实路径的项（地址栏给的是「视频」这种显示名）会被跳过，其余照常还原。

## 设置

**独立的设置窗口**：标签条最右边那枚齿轮，或者标签条空白处右键→「更多选项」，
或者**托盘图标右键 → 设置 → 更多选项…**（托盘右键里另有「书签管理器」「历史记录管理器」两条直达）。窗口分两页：
**「常规」**（下面这些设置项；顶部写程序名 / 版本 / 简介）和
**「快捷键」**（程序自有热键改键 + 全部恢复默认）。
**托盘图标右键里的「设置」还是菜单形式**（内容完全一样 —— 两边都由 `SettingsMenu` 里
那一份规格生成，加设置项不会漏一边）；菜单末尾的「更多选项…（打开设置窗口）」就是开这个窗口。

存在**程序目录下的 `data\settings.json`**（**JSON格式**；读得懂老的 `settings.txt`，
第一次启动会自动迁移成JSON并把老文件改名成 `.migrated` 留着）。

JSON本体不支持注释，所以每一项的说明写在以 `_` 开头的键里 —— 那既是合法JSON，打开文件也看得懂：

| 项 | 值 | 说明 |
|---|---|---|
| `capture` | `perdesktop`（默认） / `migrate` | 捕获方式：每张虚拟桌面各一个窗口，还是全进程一个窗口+Win+E搬过来（1.0.0的老做法） |
| `keeptabs` | `true`（默认） / `false` | 是否保留标签页；关掉就是每次打开都只有一个「此电脑」 |
| `theme` | `system`（默认） / `light` / `dark` | 颜色模式 |
| `tabwidth` | `112`（默认，64~240） | 标签页宽度（逻辑像素）。**设置窗口里可直接输入数值**，不必挑预设 |
| `tabautowiden` | `true`（默认） / `false` | 自适应①：名称过长时是否自动加宽。**基准宽度 = `tabwidth`**，名字放不下才往上加，最多 400 逻辑像素 |
| `tabautofit` | `true`（默认） / `false` | 自适应②：挤不下时是否自动缩窄（不够就均分）；两个都关 = 固定宽度 + 横向滚动看其余的 |
| `favbar` | `true` / `false`（默认） | 书签栏是否显示 |
| `captureall` | `true`（默认） / `false` | 是否连「从开始菜单/桌面双击打开的文件夹」也收成标签 |
| `debug` | `true` / `false`（默认） | **Debug模式**：是否把每一步的详细过程写进 `data\log.txt`。关着时一个字节都不写（连目录都不建）。设置窗口里可以随时开关，旁边还有一个「清理日志」按钮 |
| `hotkey_*` | 例 `"hotkey_closetab": "Ctrl+Shift+W"` | 程序自有快捷键（设置窗口「快捷键」页改的就是它）。**只写改过的那几条**，没写的用默认；留空删除 = 回默认 |

「开机自启」**不在这份JSON里** —— 它的唯一真相是注册表里的启动项
（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `TabbedExplorer` 值）。
这样不会出现「JSON说开着、其实被任务管理器禁用了」这种对不上的情况。

**Debug模式**默认关着（普通用不需要一个一直变大的文件）；要查问题时在设置窗口里打开，
它下面那行会实时显示 `data\log.txt` 现在多大，旁边就是「清理日志」。
日志超过 1 MB 时下次启动会自动轮转成 `log.txt.prev.txt`（只留一份）。

改完立刻生效（切捕获方式还会把记忆搬个家，只在目标那一边还空着时才搬）。

⚠ **颜色模式的限制**：嵌进来的explorer是**独立进程**，它按**系统**主题画自己那一片，
我们改不了别人进程的开关。所以强制浅/深只改得动我们自己画的外壳
（标签条/书签栏/设置窗口/菜单/四周边框），文件列表仍跟系统 —— 设置窗口底部那条说明就是这一条。
来回切颜色模式不会再「花屏」：切到哪一档都把嵌进来那棵窗口树重新上一遍主题，再强制重画一次
（包括预热好的备用标签）—— 不会只剩一块深或一半深一半浅。

## 数据与便携

`settings.json`（设置）、`desktops.json`（标签记忆）、`history.json`（历史）、
`favorites.json`（书签栏）、`log.txt`（日志）
都在**程序目录的 `data\`** 下 —— 整个文件夹拷到别的机器/U盘就能直接用，不往系统里写东西
（除了可选的「开机自启」那一个注册表值）。
程序目录写不动时（比如放进 `Program Files`）自动退回 `%APPDATA%\TabbedExplorer`。
从旧版本升上来的第一次启动，会把老位置的数据抄一份过来（只补缺，不覆盖）。

## 来源与致谢

- 灵感来自 [QTTabBar](http://qttabbar.wikidot.com/) 这类「给资源管理器加标签页」的老工具。
  它是**进程内的 shell 扩展**（注入 explorer.exe），能力很强，但和 Win10 的系统更新一直打架。
  本项目走的是另一条路：**跨进程 `SetParent` 把真正的资源管理器窗口搬进自己窗口**，
  不注入、不装 shell 扩展、不改系统文件 —— 外壳自己画，里面那套文件列表还是 Windows 原版的。
- 本仓库**不包含 QTTabBar 的任何代码**，也不需要装它；下面那个卸载脚本只是给「以前装过」的人清理用。

## 卸载QTTabBar

两套并存会抢Win+E，必须二选一。`uninstall_qttabbar.bat` 会卸掉机器上已装的QTTabBar（卸完需要重启资源管理器）。

## 它不做什么

- 不重画文件列表（借Windows原版的，所以不会有「像但不一样」的地方，也不会有兼容问题）。
- 不修改 `explorer.exe`、不装shell扩展、不写注册表（除了可选的启动项）。
- 不往系统目录写东西；不联网。

## 一个已知取舍：自绘标题栏删掉了

嵌进来的资源管理器窗口是**子窗口**，子窗口没有非客户区 —— 而它那条**快速访问工具栏**
（属性/新建文件夹/撤销…）恰好画在标题栏那一条里，搬进来之后就空了，加回 `WS_CAPTION` 也拿不回来。
所以从1.5.0起：**标签条直接顶到窗口最上面**，窗口的最小化/最大化/关闭并到标签条最右边。
原来仿的那排图标删了 —— 那些命令本来就都在嵌进来的资源管理器自己的功能区里（文件 / 主页 / 共享 / 查看）。

**资源管理器左上角那排功能（快速访问工具栏）抓不回来** —— 原因就是上面这条（子窗口没有非客户区）。
这件事**只写在这份文档里**，程序里不再写提示文字。
